Abstract

We present DeepBA (Deep Bundle Adjustment), a graph neural network (GNN) that recovers camera poses, intrinsics, and scene structure from 2D matches across an arbitrary number of views. Rather than solving a non-linear least-squares problem per scene, DeepBA amortizes bundle adjustment into a learned graph network that iteratively refines its estimate from geometric residuals. Where classical SfM computes its updates analytically and needs careful initialization, DeepBA learns them and converges from a cold start. It is trained with scale-invariant supervision (ground-truth rotation, translation direction, and intrinsics, plus reprojection self-consistency), so datasets with arbitrary metric units can be mixed without per-scene normalization. DeepBA is decoupled from the matcher. At 2.04M parameters, it outperforms prior learned SfM from matches on scene reconstruction and on most pose metrics, is competitive with classical SfM at moderate accuracy thresholds and overtakes it in wall time as the view count grows, and approaches monolithic image-to-geometry transformers such as VGGT (~1.2B parameters) with greater modularity.

Method

Key idea 1: A lightweight GNN for learned updates that mimic classical bundle adjustment

Each iteration reads the current state and predicts the next update of poses, focal lengths and depth. The same small network runs for every iteration and every scene. With 2.04M parameters, it is about 590× smaller than VGGT (~1.2B).

Key idea 2: A track-free state

Following the track-free idea of TFD-SfM, the state is one pose, one focal length and one depth map per image. Pairwise matches are enough, so no tracks have to be built, and any matcher can be plugged in.

Key idea 3: Scale-invariant supervision

Rotations, translation directions and intrinsics are supervised, plus reprojection self-consistency. Datasets with arbitrary metric units are mixed without per-scene normalization.

    Localization: DeepBA vs PnP and HLoc

    DeepBA localizes a new image with the same refinement step it uses for reconstruction. The map stays frozen, and only the query camera and its depth are refined, so DeepBA needs neither PnP nor the query's intrinsics.

    One query camera, iteration by iteration

    CO3Dv2 hydrant, query frame 10
    CO3Dv2 hydrant, query frame 42

    One held-out image registered against the frozen 25-image DeepBA map (blue cameras and points). The query camera (green) starts at the mean pose of the map cameras (their chordal-mean rotation and mean centre), the same start for every query, with no PnP estimate. DeepBA's update moves it, together with its lifted 3D points, onto the map. After 10 iterations the rotation error is 3.5° (frame 10, from 109°) and 4.0° (frame 42, from 19.1°). Grey: the ground-truth camera.
